# Material Symbols Rounded used by Journey

Download each symbol from https://fonts.google.com/icons with **Style: Rounded**, weight 400, grade 0, optical size 24,
as **Android** (XML vector drawable). Save into `app/src/main/res/drawable/` using the file names below.

- Outline (Fill off): `rounded_<name>_24px.xml`
- Filled (Fill on): `rounded_<name>_fill_24px.xml`

`rounded_<name>_24.xml` and `rounded_<name>.xml` are also recognised. Until a file is present the app
falls back to the closest Material Icons glyph, so you can add them gradually.
